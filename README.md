# prime-pro-endpoint

Подписанный указатель на сервер лицензий PRIME PRO (`hub_endpoint.json`).

Программа читает этот файл, только если основной адрес сервера не ответил.
Файл подписан ключом автора; без верной подписи программа его игнорирует,
поэтому публичность файла безопасна. Ничего секретного здесь нет.
